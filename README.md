# 梗王擂台 v0.7 — 独立联机服务器

同一个 Node 服务提供游戏网页和 WebSocket /ws；不再依赖 Vercel 或原 Sites 房间服务。
两人创建/加入 8 位房间码，分别选角并准备。服务器以 60Hz 运算同一套战斗规则，以 30Hz 同步画面。客户端只能发送按键，不能指定血量或命中结果。

## 启动
Node.js 22 或更新版本：运行 `npm ci`，然后 `npm start`。打开 http://localhost:3000。同一局域网朋友打开运行服务器电脑的局域网 IP 和端口 3000。

## 公网部署
Render 导入本 GitHub 仓库，按 render.yaml 配置部署 Web Service：Build `npm ci`，Start `npm start`，Health `/health`。也可部署到支持长期 Node/WebSocket 连接的主机。使用单实例，不启用多副本；房间存在内存中，重启会关闭房间。公网需要 HTTPS/WSS。不要将此版本当静态网站或 Vercel Function 部署。

## 当前限制
这是服务器判定试玩版，尚未实现回滚预测；高延迟网络下操作会有延迟。玩家断线需重新加入并准备；切出窗口会暂停。房间最多 100 个，最长 2 小时。免费托管的休眠和资源限制可能影响体验。尚未完成公网跨设备测试。

## 测试
`npm test`：双客户端房间、准备、角色、输入移动、伪造快照、满员、断线与回合逻辑。
