# 梗王擂台 v0.8 · 双人房间联机版

保留原有角色、美术和技能。两人通过同一服务器链接创建 / 加入房间，分别选角、准备，服务器统一计算命中、血量和回合。

新增：复制邀请链接自动填入房间码；网络中断自动重连（席位保留20秒）；网页显示服务状态；启动器验证首页、自动寻找空闲端口、保留诊断日志。公网连接失败不关闭本机服务。

## Windows 启动
已安装 Node.js 22+：解压完整试玩包，在文件夹地址栏输入 cmd，运行：

    node start-share.mjs

自动打开本机游戏。同 Wi-Fi 的朋友使用启动窗口显示的局域网地址。异地朋友需要公网通道成功连接后显示的公网地址。关闭启动窗口会停止游戏。

仅局域网，不尝试公网：

    node start-share.mjs --lan

官方 Cloudflare 连接程序放在 tools/cloudflared.exe，完整试玩包已内置（不提交到本代码仓库）。本机先启动，不依赖下载。不要关闭系统安全保护；若程序被阻止，请保留提示。

## 从源码启动

    npm ci
    npm start

默认监听 0.0.0.0:3000，部署环境使用 PORT。需要单个长期运行的 Node/WebSocket 实例。免费 Render 账号仍可能要求支付信息，本版本不承诺绕过平台账号验证。

## 联机

一方创建房间 → 复制邀请链接，或告诉对方8位房间码 → 双方选角准备。
WASD 移动，J/K/L/I 轻击/重击/技能/大招，双方使用相同按键。保持游戏在前台，切出窗口会暂停。

## 验证与限制

运行 npm test。已测试网页和图片访问、两名客户端选角准备及移动、命中扣血、回合结束、拒绝伪造血量、房间满员、断线恢复，以及运行实际浏览器端网络代码接收双方快照。
当前环境无法访问浏览器预览，不能声称完成视觉验收。临时公网服务在本执行环境被网络限制，公网跨设备质量尚未验证。没有实现回滚预测，高延迟时操作有延迟。房间存在内存中，服务重启后房间关闭。
