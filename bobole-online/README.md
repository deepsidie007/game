# 博博乐 · 好友牌局

基于 2026-08-19 的《博博乐_反赌博剧情版_新增21点.html》新增独立联机入口。原版完整保留于 `/solo`。

## 功能

- 2–6 人好友房间、6 位邀请房间码、手机和电脑布局。
- 联机德州扑克（四轮下注、全下、边池、平分）、炸金花（看牌、跟注、加注、指定对手比牌）。
- 同桌二十一点（共用庄家、独立结算、天然21点、双倍）和庄闲对决（标准补牌、同局结果）。
- 服务器使用系统加密随机数洗牌、发牌和结算。SSE 只传递当前玩家有权查看的牌。
- HttpOnly 会话、刷新重连、版本号防止重复操作、45 秒超时处理、房主离线后转移。
- 筹码不足20时可在局间领取1000练习筹码。无充值、提现、支付或实物兑换。

## 运行与测试

Node.js 22 或更新版本，无第三方运行依赖。

```sh
cd bobole-online
npm test
npm start
```

打开 `http://localhost:3000`。用两个浏览器或独立无痕会话模拟两位玩家；同一浏览器会话共享同一个玩家身份。

## Render 配置

从仓库独立分支 `bobole-online-20261118` 创建 **Web Service**：

| 项目 | 设置 |
| --- | --- |
| Runtime | Node |
| Build command | `cd bobole-online && npm test` |
| Start command | `node bobole-online/server.js` |
| Health check | `/health` |
| Instance | Free（试玩） |
| Suggested region | Singapore |

应用监听 `0.0.0.0` 和 `PORT`。同源 HTTP 接口和 SSE，无额外前端部署或跨域配置。

## 已知范围

- **这是运行期好友房版本**：房间、会话、筹码放在单个进程内存中。服务重启、重新部署或空闲休眠后会重置；不提供永久账号或跨进程共享。不能横向扩容到多个实例。
- Render Free 空闲后可能休眠，重新访问需等待启动。正式长期运营应另加持久化数据库和重连恢复方案。
- 原版秘密任务、身份事件、反赌博剧情、商店、借贷和老虎机保留为单机内容；联机筹码与单机存档独立。
- 联机牌桌采用文档中列出的基础规则；二十一点无分牌、保险、投降。炸金花10圈后自动摊牌，单注和下注额有明确上限。
- 玩家断线保留座位，超时自动弃牌／停牌／旁观。主动离开需在局间进行。
- 自动化测试覆盖规则、边池、隐私、两个独立HTTP会话、SSE、版本冲突、刷新会话和跨来源请求。当前执行环境限制 Chromium 启动，尚未完成真实浏览器视觉与交互验收；上线后需再验证两个独立客户端的真实操作。
