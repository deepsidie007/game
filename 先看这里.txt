梗王擂台 v0.7 · Windows 免绑卡联机试玩包

1. 先把 ZIP 全部解压到普通文件夹，不要直接在压缩包里运行。
2. 电脑需安装 Node.js 22 或更新的 LTS 版本：https://nodejs.org/
   如果未安装，双击启动脚本会打开官网；安装完成后重新双击即可。
3. 双击「开始联机.bat」。首次会从 Cloudflare 官方 GitHub 下载 cloudflared.exe，可能需要等待。
4. 窗口出现 https://某个名字.trycloudflare.com 后，把这个链接发给朋友。链接也会保存到「分享链接.txt」。
5. 双方都用这个公网链接打开游戏。一方选择「联机 · 房间对战」并创建房间，把 8 位房间码发给另一方。
6. 对方加入房间；双方选择角色并点击准备。

按键：WASD 移动，J 轻击，K 重击，L 技能，I 大招。
所有人都使用同一套按键，服务器会分配左右角色。

保持电脑开机、网络连接和启动窗口运行。停止时在启动窗口按 Ctrl+C，然后按提示退出。每次重启会生成新的临时链接。
关闭启动窗口后链接失效；房间不保存。这个包不需要绑定银行卡、注册 Cloudflare 或配置路由器端口转发。

首次下载需要访问 GitHub；下载失败时，保留提示并截图反馈。不要关闭安全软件或绕过系统安全拦截。
如果生成链接但网页打不开，可能是当前网络无法访问临时域名；换网络试一次，仍失败请截图。
双方保持游戏窗口在前台；切到其他窗口会暂停。此版没有回滚预测，高延迟会影响格斗手感。

已在开发环境测试双客户端选角、准备、移动、血量判定、回合、断线。
启动脚本语法已检查，但未在真实 Windows 电脑执行，公网跨设备效果需要你和朋友实测。
